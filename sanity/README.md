# Momentum Magazine - Sanity CMS Backend Studio

This is the official Sanity Studio backend for Momentum Magazine.

## Quick Start

1. **Install Dependencies**:
   ```bash
   cd sanity
   npm install
   ```

2. **Start Local Sanity Studio**:
   ```bash
   npm run dev
   ```

3. **Deploy Sanity Studio to Cloud**:
   ```bash
   npm run deploy
   ```

## Schema Types Included:
- **`post`**: Editorial articles, cover stories, and news.
- **`category`**: Industry sectors and topic tags.
- **`author`**: Staff writers, columnists, and contributors.
- **`leader`**: Executive directory profiles.
- **`startup`**: Founder & startup watchlist items.
- **`event`**: Editorial summits and briefings.
- **`magazine`**: Quarterly print/digital magazine issues.
